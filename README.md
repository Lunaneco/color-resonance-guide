# COLOR RESONANCE 解体新書

ゲーム version 1.18.0（ソース commit `3ef8823`）に対応した静的 Web アプリです。

- `dist/index.html`: 全74ステージ、難易度別報酬、30スキル、43装備、素材、ミニゲームを調べる攻略ページ。
- `dist/story.html`: 本編9編、復興9編、交流・後日談3編、最終章「灰色の継ぎ目」の本文、選択肢、17ボスの戦闘会話を読む物語ページ。
- `dist/data.json` と `dist/story-data.json`: 実際のゲーム定義から抽出したデータ。
- `dist/media/`: ゲームで使用しているイラスト・アイテム画像。

ビルドや外部ライブラリは不要です。`dist` を HTTP サーバーで配信してください。Sites の配信設定は `.openai/hosting.json` にあります。

しおり、文字サイズ、攻略チェックリストは、このページを開いたブラウザだけに保存します。ゲームのセーブデータは操作しません。復興編やクリア後の情報は、表示設定を切り替えて閲覧できます。

加入順はグラン→アイビー／ヴァルド（順不同）→スピネルです。パレット王はクロムと同じく人間の王で仲間にならず、宝具「双彩の王笏」（1ターンに2体まで召喚）を託します。旧ルノワールはノアール（愛称ノア）、ヴァルドは紅い竜です。最終章は復興編と馨のカフェのあと、テラ・コッタから開き、馨が最後の相手になります。物語ページは第三幕の加入順を選ぶと本文・会話と読む順が切り替わります。設定上のクリアはクロム撃破後です。マリーの加入は復興第4章の救出後、グランとヴァルドの意気投合はヴァルド戦後です。透明の国の名称はクリスタリアで、色の国々の外にある光の国です。

公開前の確認では Chromium / WebKit で本文と会話の収録、章選択、全文検索、しおり、攻略との相互リンク、全ステージ詳細、スキル強化計算、報酬、灯りパズルの解法を検証しています。320 / 390 / 667 / 1440 px の表示も確認し、6件のブラウザテストがすべて成功しました。

データ再生成: `node scripts/export-game.cjs /path/to/color-resonance`。ゲームのコミットと定義を読み取り、現在のカタログを更新します。
