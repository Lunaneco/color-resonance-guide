# COLOR RESONANCE 解体新書

ゲーム version 1.25.0（ソース commit `d002d80`）に対応した静的 Web アプリです。

- `dist/index.html`: 全77ステージ、陣取り戦3戦と虹の近衛七人、難易度別報酬、30スキル、43装備、素材、ミニゲームを調べる攻略ページ。
- `dist/story.html`: 本編9編、復興9編、交流2編、最終章「灰色の継ぎ目」の本文、選択肢、17ボスの戦闘会話を読む物語ページ。
- `dist/data.json` と `dist/story-data.json`: 実際のゲーム定義から抽出したデータ。
- `dist/media/`: ゲームで使用しているイラスト・アイテム画像。

**公開ページ:** https://lunaneco.github.io/color-resonance-guide/ （攻略） / https://lunaneco.github.io/color-resonance-guide/story.html （物語）

ビルドや外部ライブラリは不要です。`main` へ push すると `.github/workflows/pages.yml` が `dist` を GitHub Pages へ公開します。手元では `dist` を HTTP サーバーで配信してください。

しおり、文字サイズ、攻略チェックリストは、このページを開いたブラウザだけに保存します。ゲームのセーブデータは操作しません。復興編やクリア後の情報は、表示設定を切り替えて閲覧できます。

本編の陣取り戦（第一幕アクアミスト・第四幕石の子の村・第五幕虹の城下町）は、指揮点・旗の占領・迎撃・土嚢・霧（潜伏）で戦う戦場のヴァルキュリア風の戦いです。敵の本陣と旗には、パレット王の眷属「虹の近衛」が指揮官として立ちます。物語ページでは、その場面の戦闘に近衛の台詞が出ます。

加入順はグラン→アイビー／ヴァルド（順不同）→スピネルです。パレット王はクロムと同じく人間の王で仲間にならず、宝具「双彩の王笏」（1ターンに2体まで召喚）を託します。旧ルノワールはノアール（愛称ノア）、ヴァルドは紅い竜です。復興編はクロムが止めたあとも滲む黒の出どころを追う話で、アクロマは登場しません。馨は復興編に同行せず、最終章は復興編のあとテラ・コッタから開きます。クロムと馨はそこで初めて出会い、馨が最後の相手になります。物語ページは第三幕の加入順を選ぶと本文・会話と読む順が切り替わります。設定上のクリアはクロム撃破後です。マリーの加入は復興第4章の救出後、グランとヴァルドの意気投合はヴァルド戦後です。透明の国の名称はクリスタリアで、色の国々の外にある光の国です。

公開前の確認では Chromium / WebKit で本文と会話の収録、章選択、全文検索、しおり、攻略との相互リンク、全ステージ詳細、スキル強化計算、報酬、灯りパズルの解法を検証しています。320 / 390 / 667 / 1440 px の表示も確認し、6件のブラウザテストがすべて成功しました。
